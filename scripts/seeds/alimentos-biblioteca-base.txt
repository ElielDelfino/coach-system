RESSALVAS:

1. TACO (Tabela Brasileira de Composição de Alimentos, NEPA/Unicamp): referência
   oficial brasileira, usada por nutricionistas, ANVISA e SUS. Os valores aqui
   estão arredondados (uma a duas casas decimais) — discrepâncias de ±5% em
   relação à tabela original são esperadas e aceitáveis para uso clínico/coaching.

2. Suplementos: valores são MÉDIA de marcas grandes (Growth, Integralmédica,
   Max Titanium, Black Skull). Marcas específicas variam em ±15%. Em prescrição
   estrita, o ideal é o aluno informar a marca e atualizar o registro.

3. "Scoop padrão" para suplementos: convenção interna = 30g para whey/caseína,
   25g para hipercalórico, 5g para creatina/BCAA. Se o rótulo do aluno usar
   medidas diferentes, recalcular.

4. Alimentos "grelhados/cozidos" usam valores pós-preparo (com perda de água),
   alinhados com TACO. Não confundir com peso cru.

5. NÃO substitui prescrição nutricional profissional. É uma biblioteca base para
   o coach montar planos — alunos com condições clínicas específicas (diabetes,
   renal, etc.) exigem revisão por nutricionista.

CONCLUSÃO: A base é VÁLIDA e CONFIÁVEL para uso em coaching fitness/hipertrofia
generalista. Para nutrição clínica especializada, exige curadoria adicional.
